
# CSAPP 第 2 章
- 位运算：& | ^ ~ << >>
- -1 补码 = 4294967295
- 有符号转无符号会变
# CSAPP 2.1.2 字数据大小
- char=1, short=2, int=4, long=8, 指针=8（64位）
- INT_MAX = 2147483647
- INT_MIN = -2147483648
- UINT_MAX = 4294967295
- sizeof 看大小
# CSAPP 2.1.3 寻址和字节顺序
- 多字节数据在内存里有两种排法
- 小端：低位字节在低地址，78 56 34 12
- 大端：高位字节在低地址，12 34 56 78
- x86_64 是小端
- 网络字节序是大端
- 用 unsigned char* 逐字节看内存
# CSAPP 2.1.4 表示字符串
- 字符串 = 字节数组
- 每个字符用 ASCII 编码
- "hello" = 68 65 6c 6c 6f 00
- 0x00 是结束符
- 'A'=65, 'a'=97, '0'=48, ' '=32
# CSAPP 2.1.5 表示代码
- 代码也是字节，存在内存里
- 函数有地址，函数名可当指针
- show_bytes 可以看函数机器码
- 机器码对应汇编指令
- gcc -S 看汇编
# CSAPP 2.1.6 布尔代数
- 只有 0 和 1
- & 与：都为 1 才 1
- | 或：有一个 1 就 1
- ^ 异或：不同为 1
- ~ 非：取反
- 0x0F & 0x33 = 0x03
# CSAPP 2.1.7 位级运算
- & | ^ ~ << >>
- a & b：都为 1 才 1
- a | b：有一个 1 就 1
- a ^ b：不同为 1
- ~a：取反
- a << 1：左移一位，等于乘 2
- a >> 1：右移一位，等于除 2
- x & 1 判断奇偶
# CSAPP 2.1.8 逻辑运算
- && || ! 是逻辑运算，结果只有 0 或 1
- & | ~ 是位运算，结果是一个数值
- 逻辑运算有短路特性：
  - 0 && x 不执行 x
  - 1 || x 不执行 x
- 常用：if (p != NULL && *p == 5) 防止空指针崩溃
# CSAPP 2.1.9 移位运算
- << 左移：低位补 0，等于乘 2^n
- >> 右移：无符号高位补 0（逻辑右移），有符号高位补符号位（算术右移）
- 左移可能溢出
- 移位不能为负数，也不能大于等于字长
