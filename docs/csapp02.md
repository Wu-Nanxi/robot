- 位运算：& | ^ ~ << >>
- -1 补码 = 4294967295

# CSAPP 2.1.2 字数据大小
- char=1, short=2, int=4, long=8, 指针=8（64位）
- INT_MAX = 2147483647
- INT_MIN = -2147483648
- UINT_MAX = 4294967295
- sizeof 看大小
# CSAPP 2.1.3 寻址和字节顺序
- 多字节数据在内存里有两种排法
- 小端：低位字节在低地址，78 56 34 12
- 大端：高位字节在低地址，12 34 56 78
- x86_64 是小端
- 网络字节序是大端
- 用 unsigned char* 逐字节看内存
# CSAPP 2.1.4 表示字符串
- 字符串 = 字节数组
- 每个字符用 ASCII 编码
- "hello" = 68 65 6c 6c 6f 00
- 0x00 是结束符
- 'A'=65, 'a'=97, '0'=48, ' '=32
